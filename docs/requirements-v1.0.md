# 拍照识物学英语 微信小程序 需求文档 v1.0

> 状态：基本确认 ｜ 日期：2026-11-08 ｜ 需求方：ellie
> 产品名暂定「随手拍英语」，可再改。

---

## 1. 背景与目标

**痛点**：中文母语、学过英语的人，在生活场景里经常想不起常见物品怎么说，比如锅碗瓢盆、米面粮油。背单词 App 里的词偏考试，覆盖不到"眼前这个东西"。

**产品一句话**：看到不会说的东西，拍一下就知道英文叫什么、怎么用，并自动收进单词卡包，之后按复习计划巩固。

**目标**
- 从拍照到看到英文结果，用时控制在 5 秒内
- 拍过的词不用手动整理，AI 自动归类
- 通过复习机制让用户真正记住，而不只是查过一次

## 2. 目标用户

- 中文母语、有一定英语基础的成年人（学过英语，但生活词汇薄弱）
- 典型场景：做饭、逛超市、收拾家、出国前准备、陪孩子学英语
- 界面语言：中文；内容：中英对照

## 3. 版本范围

| 模块 | MVP（第一版） | 第二版及以后 |
|---|---|---|
| 识别 | 拍照 / 相册选图识别，多物品点选 | 连续扫描模式、离线常用词库 |
| 单词详情 | 第 5.2 节 a～g 全部内容 | 用户纠错反馈、更多例句 |
| 卡包 | 按类别自动归类 + 按地点模式切换，手动改分类 | 自定义卡包封面、卡包分享 |
| 复习 | 间隔重复 + 看图说词 + 每日提醒 | 跟读打分、排行榜、打卡日历 |
| 账号 | 微信一键登录，云端存储 | 多端同步（App/网页） |
| 分享 | 单词卡片生成分享图、转发给好友 | 卡包整体分享、好友 PK |
| 商业化 | 每日 10 次免费 + 点数购买 | 会员订阅 |

## 4. 核心用户流程

```
打开小程序 → 拍照 / 选相册图片
   → AI 识别（检测到多个物品时，在图上标出，让用户点选一个或多个）
   → 单词详情页（英文、音标、发音、中文、例句、搭配、辨析、英美差异）
   → 自动存入对应卡包（页面提示"已存入【厨房用品】"，可一键改分类）
   → 进入复习计划，按时提醒复习
```

## 5. 功能需求

### 5.1 拍照识别

- 入口：首页正中大按钮"拍一拍"，支持拍照和相册选图
- 识别结果：
  - 单物品：直接进入详情页
  - 多物品：在原图上框出识别到的物品并标注英文，用户点选要学的（可多选，每个物品单独成卡）
- 识别失败或置信度低时：提示"没看清，换个角度再拍一次"，同时给出 2～3 个候选让用户选；**失败不扣次数**
- 已经学过的词再次被拍到：提示"这个你学过啦"，直接打开原卡片，**不扣次数**，并记一次"再次遇见"（用于复习权重）

### 5.2 单词详情页（a～g 全部展示）

| 编号 | 内容 | 说明 / 示例 |
|---|---|---|
| a | 英文单词 + 音标 + 发音 | 美音 / 英音可切换，点击播放 |
| b | 中文名 | 炒锅 |
| c | 生活场景例句 2～3 句 | "Could you pass me the colander?" 附中文翻译，例句可点读 |
| d | 常用搭配 | a pot of rice / boil water in a pot |
| e | 易混词辨析 | pot / pan / wok 的区别，用一两句话加示意说明 |
| f | 英美说法差异 | faucet（美）/ tap（英）；没有差异时不显示此模块 |
| g | 多物品点选 | 见 5.1 |

- 详情页底部显示：所属卡包（可改）、拍摄原图缩略图、加入时间
- 内容由 AI 生成，需保证例句地道、贴近日常口语，不用考试式例句

### 5.3 单词卡包

**两种归类模式，可在卡包页顶部开关切换：**

1. **按物品类别（默认）**：AI 按物品类别自动归类，例如 厨具、餐具、食材调料、家电、清洁用品、洗护用品、家具、文具、衣物、数码产品……
2. **按拍摄地点**：按"在哪拍的"归类，例如 厨房、浴室、卧室、超市、办公室、户外。
   - 地点判断方式：AI 根据照片背景推断场景，用户可在详情页修改。不读取 GPS 定位（避免隐私授权，也因为 GPS 分不出"厨房"和"卧室"）。

**规则**
- 同一张卡同时带"类别"和"地点"两个标签，切换模式只是换一种分组视图，不会复制或丢失数据
- 用户可手动修改分类、新建自定义卡包、把卡片移入自定义卡包
- 卡包列表显示：卡包名、单词数、待复习数
- 卡片浏览：正面图片，翻面看英文和详情；支持按加入时间 / 熟练度排序

### 5.4 复习机制

- **间隔重复**：每张卡按记忆曲线安排复习，间隔示例 1 → 2 → 4 → 7 → 15 → 30 天；答对拉长间隔，答错重置到较短间隔
- **复习题型（MVP）**
  1. 看图说词：显示照片，用户回想英文后翻面自评"记得 / 模糊 / 忘了"
  2. 听音选图：播放发音，从 4 张图片里选对的
  3. 看中文选英文：四选一
- **每日提醒**：通过微信订阅消息提醒"今天有 N 个词待复习"（需要用户授权订阅；微信一次性订阅消息每次授权只能推送一条，提醒频率受此限制）
- 首页显示：今日待复习数、已掌握词数、连续学习天数

### 5.5 账号与数据

- 微信一键登录，不需要手机号注册
- 所有卡片、图片、复习记录存云端，换手机登录后自动恢复
- 用户可删除单张卡片，也可在设置里注销账号并清空所有数据

### 5.6 分享

- 单词卡片可生成分享图（物品照片 + 英文 + 音标 + 一句例句 + 小程序码），保存到相册后可发朋友圈
- 可直接转发给微信好友 / 群，好友点开能看到这张卡片，并引导使用小程序

### 5.7 识别额度与点数

- 每个用户每天免费识别 **10 次**，每天 0 点（北京时间）重置
- 计次规则：识别成功才扣次数；识别失败、重复拍到已学过的词不扣；一张图选多个物品算 1 次
- 免费次数用完后：提示"今日免费次数已用完"，可选择购买点数，或等明天
- 点数：1 点 = 1 次识别，点数长期有效，优先消耗每日免费次数，免费次数用完再扣点数
- 点数价格档位（已确认）：6 元 30 点、18 元 100 点
- **MVP 阶段的支付开关**：MVP 用个人主体上线，个人主体开不了微信支付。因此付费功能照常开发，但用一个后台开关默认关闭，购买入口不显示，额度用完只提示"明天再来"。等迁移到个体工商户主体、开通微信支付商户号后，打开开关即可上线付费，不用改版发版。
- 显示位置：首页显示"今日剩余 X 次 · 点数 Y"

## 7. 数据结构（草案）

- **用户**：openid、昵称头像、发音偏好、每日已用次数、点数余额、注册时间
- **单词卡**：用户、英文、音标（美/英）、中文、例句（含翻译）、搭配、辨析、英美差异、类别标签、地点标签、自定义卡包、原图地址、创建时间
- **复习记录**：卡片、下次复习时间、当前间隔、熟练度、复习历史
- **卡包**：用户、名称、类型（系统类别 / 系统地点 / 自定义）
- **点数流水**：用户、变动数、原因（购买 / 消耗）、订单号、时间

## 8. 技术方案建议（供讨论）

- **前端**：微信小程序原生开发
- **后端与存储**：微信云开发（云函数 + 云数据库 + 云存储），免运维、和微信登录天然打通，适合 MVP；用户量上来后再考虑自建服务
- **识别与内容生成**：用多模态大模型一次完成"看图识物 + 生成英文、例句、搭配、辨析、英美差异、分类标签"，输出结构化 JSON。候选：
  | 方案 | 优点 | 注意点 |
  |---|---|---|
  | 国内多模态大模型（如通义千问 VL、豆包视觉模型等） | 国内访问稳定，合规路径清晰 | 英文例句地道程度需实测 |
  | 海外大模型（如 Claude、GPT 等） | 英文内容质量高 | 国内服务器调用和合规上有障碍，面向国内用户上线不推荐直接使用 |
  | 传统图像识别 API + 大模型生成文本 | 识别成本可能更低 | 两段调用，延迟和开发量更大 |
  
  建议：MVP 阶段先用国内多模态大模型，开发时拿 30～50 张生活照片实测识别准确率和例句质量再定。
- **发音**：语音合成（TTS）接口生成美音 / 英音，结果缓存，同一个词只生成一次
- **成本控制**：同一英文词的详情内容全局缓存复用，只有识别这一步每次都调用

## 9. 非功能需求

- 性能：识别到出结果 ≤ 5 秒，期间显示加载动画和"正在认真看…"之类的提示
- 内容安全：用户上传的图片和 AI 生成的文本都需过微信内容安全接口检测
- 隐私：只申请相机和相册权限，不申请定位；需提供隐私协议，说明图片会上传到服务器用于识别
- 可用性：识别服务异常时给出友好提示，不扣次数

## 10. 上线前置条件与待确认问题

**上线前置（需要你这边准备）**
1. **注册小程序账号**：个人主体的小程序**无法开通微信支付**，而"购买点数"需要支付，所以建议以**企业或个体工商户**主体注册。如果先用个人主体开发 MVP，就先不做付费，只做每日 10 次限额。
2. **iOS 虚拟支付限制**：微信小程序在 iOS 上售卖虚拟商品（点数属于虚拟商品）有平台限制，具体政策需要在开发前核实；可能需要 iOS 端隐藏购买入口或走微信的虚拟支付方案。
3. **AI 合规**：面向国内公众提供生成式 AI 服务，涉及大模型备案 / 登记要求，调用已备案的国内大模型可以简化这部分；小程序类目也需要选对（如"教育 > 在线教育"或"工具"类），具体以微信审核要求为准。

**已确认（2026-11-08）**
1. 点数价格：6 元 30 点 / 18 元 100 点
2. 产品名：暂用「随手拍英语」，上线前可再改
3. 按地点归类：AI 看照片背景推断 + 用户可改，不用 GPS
4. 复习题型：MVP 做 5.4 的三种
5. 注册主体：MVP 用**个人主体**；付费功能开发好但默认关闭，之后迁移到个体工商户主体再开启

**主体迁移说明**
- 微信支持把个人主体小程序迁移到个体工商户 / 企业主体，迁移后 AppID、用户、云开发数据保持不变（具体流程和费用以迁移时微信公众平台后台说明为准）。
- 因此 MVP 的所有数据设计（openid、点数余额、点数流水）都按迁移后可以直接沿用来做。
